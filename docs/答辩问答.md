## 1. 开场一句话

"我复现了微软 2021 年 LoRA 论文,在 SST-2 情感分类上对比**全量微调(Full FT)** 和 **LoRA**,做了 **rank** 和 **target_modules** 两组消融。"

## 2. 核心公式

`W' = W + (α/r)·BA`

- W 冻结,只训 A/B;**ΔW = BA 是低秩**(不是 W 低秩)
- **α**:缩放因子 / 超参数,控制增量影响力度;**r**:秩,决定参数量;经验取 α = r
- **α/r** 才是实际缩放系数;rank 消融设 α = r,保证 α/r = 1,**只变 rank、不变缩放**(控制变量)

## 3. 低秩的含义

A(r×d)、B(d×r),参数量 2dr = 2×8×768 = 12,288 ≪ d² = 589,824。
低秩 = 用两个瘦矩阵的乘积来近似更新,参数从 d² 降到 2dr。

## 4. 参数量算账(万能公式:**单个矩阵 A+B = 2×r×d**)

- Q/V × 12 层 = 24 个矩阵 → 24 × 12,288 = **294,912**
- 加 K = 12 个矩阵 → **147,456**
- 分类头 **592,130** = dense(768→768) + out_proj(768→2),两边都训
- LoRA 总可训练 **887,042** = 294,912 + 592,130;Full FT 124,647,170 → **约 1/140**

## 5. Adapter 对比

- Adapter(Houlsby 2019):层里串行插**非线性**瓶颈 MLP(降维→非线性→升维)→ 没法合并进 W → **增加推理延迟**
- LoRA 的 BA 是纯线性 → 可合并进 W(W' = W + (α/r)·BA)→ **零额外延迟**

## 6. 压力题:论文 95.1 vs 我们 0.9369

**立场:不算失败。** 论文 95.1 是参考上限,不是 KPI。

差异来源(6 条):
1. 随机种子 / 数据划分不同
2. 超参未严格对齐(学习率、batch、epoch、α、dropout)
3. 只训 3 个 epoch,可能未充分收敛
4. 分类头从零初始化
5. 实现 / 版本差异(论文 TensorFlow vs 我们 transformers+PEFT)
6. 论文可能用了未公开 trick

核心:验证的是"**参数效率 + 精度接近 FT + rank/target 规律**",这套逻辑在两个种子里稳定成立,这才是本项目的价值。

## 7. 初始化 B=0、A 随机(恰好一个随机、一个置零)

- **B=0 / A 随机** → ΔW = 0,从原模型出发**不扰动**预训练模型
- **都随机** → ΔW ≠ 0,一开始就**扰动**预训练模型
- **都置零** → 两边梯度恒 0,**永不更新**(真死锁)

## 8. LoRA 局限

- 缺严格数学证明(低秩是经验发现)
- r 无理论依据,只能消融实验试(→ 这正是我 rank 消融干的事)
- (可选)所有层共享同一 r,不能逐层自适应

## 9. 亲手做 / 实现

- **库**:torch / transformers(模型 + tokenizer)/ peft(加 LoRA)/ pandas(读数据)
- **数据**:SST-2,本地 `data/SST-2/*.parquet`,tokenizer 编码成 input_ids + attention_mask,DataLoader batch=16
- **加 LoRA**:`LoraConfig(r=8, alpha=8, dropout=0.1, target_modules=["query","value"])` → `get_peft_model`
- **评估**:dev accuracy;四指标 = accuracy / 参数量 / 显存 / 时间
